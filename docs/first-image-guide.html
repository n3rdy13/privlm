The words you'll see

Model (checkpoint)The image AI itself. One file, usually .safetensors, about 2 GB for SD 1.5. It decides the overall look.
LoRAA small add-on file (10–200 MB) that teaches the model a style, a character or a detail. It only works with the model family it was made for.
Trigger wordA word some LoRAs need in the prompt to switch on. It's listed on the LoRA's download page.
WeightHow strongly a LoRA applies. 0 is off, about 0.8 is typical, above 1.2 starts to distort.
Prompt and AvoidWhat you want in the picture, and what you don't (the negative prompt).
StepsHow many passes the model makes. More is cleaner but slower; 20–30 for SD 1.5.
SeedThe random start. The same seed with the same settings makes the same picture.
Start image and ChangeImage-to-image: begin from a picture and say how much to change it, from 0.1 (a little) to 1 (a lot).

Step 1: Get the files

  1. Pick a model. On Civitai or Hugging Face, filter by base model SD 1.5, the kind phones run well. For photos, CyberRealistic or Realistic Vision; for art, DreamShaper. Download the .safetensors file.
  2. Pick one or two LoRAs. Use the same filter, base model SD 1.5. On each LoRA's page, note its trigger words and recommended weight.
  3. Put them where you can find them. On the laptop, keep LoRAs in one folder, for example Documents\LoRAs. On a phone, the Files app or Downloads is fine: PrivateLM copies them in.
Only download .safetensors. Older .ckpt and .pt files can run hidden code when they're opened. Skip them unless you trust the source.

Step 2: Load the model

On your phone

  1. Open Models, tap Import → Import file and pick the model's .safetensors file.
  2. Tap the model, then Load. When the chat shows the Image gen chip, it's ready.
  3. iPhone: in Settings → Image generation, set Backend to CPU. The GPU (Apple NPU) backend can't use LoRAs or start images.

On the laptop

  1. Open PrivateLM Laptop, go to Images, click Browse… and pick the model.
  2. Click Load model. The Settings preset picks good values for it, like DPM++ 2M, 28 steps, CFG 6 for CyberRealistic.

Step 3: Write the prompt

Describe what can be seen, as short phrases separated by commas, in this order:

medium: photo of / oil painting ofsubject + 2–3 detailssettinglightframingquality words
photo of an old fisherman mending his nets on a pier, red raincoat, weathered hands, golden hour light, close-up, 85mm lens, shallow depth of field, highly detailed

For Avoid, a solid start for photos: blurry, deformed, bad anatomy, extra fingers, watermark, text, cartoon

Stuck for words? On the laptop, ✨ Prompt helper… builds the prompt from a plain idea and a few choices. Give me ideas writes several versions for the Queue.

Step 4: Add a LoRA, properly

  1. Phone: tap Options next to the Image gen chip → Add LoRA, pick the file, leave it switched on.
    Laptop: LoRAs… → Choose… your folder, tick the LoRA.
  2. Set its weight to the LoRA page's suggestion, or 0.8 if there isn't one.
  3. Add its trigger word to the prompt. Without it, many LoRAs do nothing.
  4. Start with one LoRA. Add a second only when the first looks right, and lower both a little when they're together.

Step 5: Start from an image

Image-to-image keeps a picture's layout and changes it with your prompt.

  1. Phone: Options → Photos or Camera. Or open an image in the chat and tap the wand, Use as starting image.
    Laptop: tick Start from an image, then Choose… or click a gallery image and Use selected.
  2. Set Change: 0.3 to fix details or restyle, 0.6 to change what's in it, 0.8 to keep only the rough layout.

Faster with your phones

Making several images? The laptop and phones can share the work, each making whole images at the same time.

  1. On each phone, load the same model, then Settings → Phone cluster → turn on Images for a laptop.
  2. On the laptop's Images tab, click Find nearby, pick Variations or Queue, and click Generate.
  3. LoRAs and the starting image are sent to the phones automatically. Keep PrivateLM open on them.

When it doesn't look right

What you seeTry this
Melted, noisy or "fried" coloursLower the LoRA weight to 0.5–0.7, use one LoRA, or lower CFG to 5–6.
The LoRA changes nothingAdd its trigger word, check it's switched on, and check it's an SD 1.5 LoRA for an SD 1.5 model.
Garbage or grey static with a LoRAThe LoRA was made for another model family (SDXL, Flux, Pony). Get the SD 1.5 version.
Blurry or unfinishedMore steps (20–30). Only LCM or Turbo models and LoRAs work in 4–8.
Bad hands and facesAdd "bad anatomy, extra fingers" to Avoid, show fewer people, use a portrait framing.
Start image barely changes, or changes too muchRaise or lower Change in steps of 0.1.
iPhone says it needs the CPU backendSettings → Image generation → Backend: CPU, then load the model again.
A phone is skipped by the laptopUpdate PrivateLM on it. Older versions can't take LoRAs or start images.
